# Data dictionary: data/payouts.csv

Fully synthetic data generated by `generate_data.py`. 12,000 rows,
one per payout, January to June 2026. No real people, companies, or
transactions.

| Column | Type | Description |
| --- | --- | --- |
| `payout_id` | string | Unique payout identifier, `PO-00001` format. Primary key. |
| `issued_at` | datetime | When the sender issued the payout. |
| `sender_id` | string | Fictional sender company ID (`SND-001` to `SND-012`). |
| `sender_name` | string | Fictional sender company name. |
| `sender_industry` | string | Sender industry segment. |
| `campaign_type` | string | Use case: Employee recognition, Customer rebate, Research incentive, Sales SPIF, Referral bonus, or Survey incentive. |
| `reward_type` | string | Gift card, Prepaid card, ACH transfer, or Charity donation. |
| `amount_usd` | decimal | Face value of the payout in US dollars. |
| `recipient_country` | string | Recipient country code (US, CA, GB, AU, DE). |
| `delivered_at` | datetime, nullable | When the delivery email was delivered. Empty means delivery failed. |
| `reminder_sent` | boolean | True if a reminder was sent 72 hours after delivery because the payout was still unclaimed. |
| `claimed_at` | datetime, nullable | When the recipient claimed the reward. Empty means not claimed by the snapshot date. |
| `status` | string | `claimed`, `pending_unclaimed`, `expired_unclaimed`, or `delivery_failed`. See `metrics_definitions.md`. |
